## Key Decisions
- PowerShell `[System.Drawing.Icon]::ExtractAssociatedIcon()` replaces the unreliable Shell API (`SHGetFileInfoW`+`DrawIconEx`)
- Inline view swapping (clear `_buttons_frame`, build picker, rebuild editor on OK/Cancel) replaces Toplevel popups — more reliable, no focus/stacking issues
- Combined icon + colour picker in one inline view (MDI grid above colour swatches) keeps the interaction compact
- `_build_button_edit(parent, slot, form_data=None)` separates the slot identity (for delete) from form values
