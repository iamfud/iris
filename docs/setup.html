1. Overview

Iris is a dynamic control-and-automation utility for Windows. It turns your PC into a command centre where you can control or automate lighting, run a screen-capture toolbar with annotations and OCR, pick colours, take notes, mix media and per-app volumes, monitor PC statistics, run an alarm, stopwatch, and countdown timer, and display custom button boxes in games, simulators, and apps. A conditional macro system with hotkey injection and reactive events ties it all together — for example, change your lighting to red when you enter combat.

Everything you capture and note is collected into an integrated library browser, and the whole thing is extended by plugins and addons including Home Assistant. Iris can also drive an optional physical MAX7219 LED matrix display, a floating overlay, and a phone/PWA panel for control — but it is first and foremost a general-purpose control and automation utility, not just a stats display.

The system has seven main parts:

  • Python desktop app (app/) — the core: control, capture, mixing, automation, stats, and data plumbing.
  • Capture & Library tools (capture_toolbar.py, colour_picker.py, notepad_window.py, quick_note.py) — screen captures, annotations, OCR (on every capture and standalone text grab), colour picking, and notes, all browsed from the library.
  • Automation & Media (automations.py, win_volume.py, lighting_service.py, keyboard_service.py) — conditional macros, hotkey injection, per-app volume mixing, and reactive lighting.
  • Timers & Alarms (alarm_popup.py, alarm_sound.py, stopwatch.py) — alarms plus on-screen stopwatch and countdown timer.
  • ESP firmware (firmware/ — optional) — drives the MAX7219 display from the PC.
  • HTML panel / PWA (HTML/) — a web panel for control from a browser or phone.
  • Android app (android/) — a native companion-device app.
💡 You can use Iris with just the desktop app and overlay (no hardware) — the capture, mixing, macro, and control features all work standalone; the LED display is optional.

3. Hardware & Wiring

What each part does

  • ESP8266 (Wemos D1 Mini) / ESP32 — the brain of the display. It listens on USB serial for commands from the PC and drives the LED matrix over SPI.
  • MAX7219 LED matrix — 8×8 dot-matrix modules. Iris uses 4 daisy-chained modules (FC16_HW). Each MAX7219 chip drives one 8×8 panel.
  • USB cable — powers the ESP and carries serial data between the PC and the micro.

Wiring table (MAX7219 → D1 Mini)

MAX7219 PinD1 Mini PinNotes
VCC5VPower (also feeds the LED matrix).
GNDGNDCommon ground.
DIND7 (GPIO13)SPI data in.
CLKD5 (GPIO14)SPI clock.
CSD2 (GPIO4)SPI chip select.
⚠️ The MAX7219 has a built-in failsafe: if the PC app crashes or disconnects for 60 seconds, the display forces itself off to prevent a runaway all-LEDs-on state (which can draw ~5A and melt the case). Any serial command re-activates it.

SPI wiring diagram

MAX7219 | D1 Mini VCC ─────────── 5V GND ─────────── GND DIN ─────────── D7 (GPIO13) CLK ─────────── D5 (GPIO14) CS ─────────── D2 (GPIO4)

4. Flashing the Firmware

The firmware lives in firmware/d1mini/main/. Follow these steps:

1

Open the sketch

Open firmware/d1mini/main/main.ino in the Arduino IDE.

2

Install board support

In File → Preferences, add the ESP8266 boards URL to "Additional Boards Manager URLs":

http://arduino.esp8266.com/stable/package_esp8266com_index.json

Then Tools → Board → Boards Manager, search "ESP8266", and install.

3

Select your board

Under Tools → Board, select your board (e.g. "LOLIN(WEMOS) D1 mini"). Set the correct Port for your USB device.

4

Upload

Click the Upload button (→). The IDE compiles and flashes the firmware.

5

Boot self-test

On power-up you'll see a 250 ms all-LEDs flash. That's the intentional boot self-test (TEST=ON), not a fault.

5. Desktop App

The Python app in app/ is the core of Iris. Here's how to run it.

1

Clone the repo

git clone https://github.com/iamfud/iris.git
cd iris
2

Install Python dependencies

pip install -r requirements.txt

This installs pressing libraries: pystray (tray icon), Pillow (rendering), pyserial (USB), requests (HTTP/HA), psutil (system stats), pywebview (HTML panel), and more.

3

Run the app

python app/main.py

The app starts in your system tray. Click the tray icon or press the global hotkey Ctrl+Alt+I to toggle the floating overlay.

6. Command & Control / Button Boxes

The heart of Iris is a dynamic button-panel system. Every button can be assigned to an action — lighting, capture, volume, media, hotkey, an app launch, or a plugin action — and organized into pages of buttons (button boxes).

What you can assign to a button

  • Lighting / OpenRGB — switch lighting profiles and colours.
  • Capture — take a fullscreen or zone screenshot with annotations; OCR runs on every capture.
  • Media & volume — play/pause/next, and per-app volume mixing.
  • Hotkeys / macros — inject a key combination or run a conditional macro.
  • Apps / shortcuts — launch an application with its icon on the tile.
  • Plugin actions — game integrations (e.g. Elite Dangerous), PC stats, vision, and more.

In-game and in-app button boxes

Button boxes aren't limited to the desk — Iris drives custom button-box overlays inside simulators, games, or apps. Gaming integrations (plugins) expose live telemetry and per-game actions so you can control anything from the ship cockpit to a production app, right where you're working.

7. Capture Toolbar & Annotations

Iris ships a transient, top-centre capture toolbar for fast screen work. Launch it from a button or the tray, then:

  • Fullscreen or Zone capture — grab the whole screen or draw a region.
  • Pixel annotations — mark up captures right before saving.
  • OCR on every capture — OCR runs automatically on every capture; the recognised text is copied to your clipboard and stored as a sidecar (capture_toolbar.py + vision.ocr_extract).
  • Capture text to clipboard — a standalone OCR action grabs text from any screen region and copies it straight to your clipboard, independent of taking a screenshot.
  • Filed into the Library — every capture and its OCR text lands in the integrated library browser, grouped per app.

Colour picking

The included colour picker runs a system-wide low-level mouse hook — grab any pixel on any screen, read its RGB/HEX, and copy it to the clipboard. It uses a safe hook-based approach that never leaves your cursor stuck.

8. Color Picker & Notepad

Beyond captures, Iris bundles everyday desk tools that all feed into one library:

  • Color Picker (colour_picker.py) — pixel-level colour grab with HEX/RGB output to clipboard, triggered from a panel button.
  • Notepad (notepad_window.py) — a built-in note window.
  • Quick Note (quick_note.py) — capture a fleeting thought in one shortcut.

Integrated Library Browser

Screenshots, OCR text, and notes are collected into the integrated library browser, grouped per application and searchable from the panel — a single place to find any capture or note.

9. Media Mixing & App Volume

Iris gives you full media transport and a true mixer, not just a mute switch:

  • Media controls — play/pause/next/previous for the active session; now-playing info with live album art via Windows SMTC (app/providers/media.py).
  • Per-application volume — win_volume.py enumerates every audio session and tracks the foreground app, letting you adjust or mute any individual app's volume without touching the master.
  • Master / active-app control — set master volume, or tune the currently active application's volume directly from a slider or button.

10. Vision System

Iris includes a generic screen-analysis ("Vision") system — not a game-specific detector. Create one or more Vision Sensors, each watching a small region of the screen and raising an Iris event when a condition is met:

  • Colour-based modes — Colour Percentage, Pixel Match, and Average Brightness within a region.
  • Event integration — when a condition crosses its threshold (rising edge), Iris can fire actions such as notifications, hotkeys, or lighting changes.
  • Calibration UI — a 5-step wizard to mark a region, pick colours, configure the condition, and test it live.

11. Alarm, Stopwatch & Countdown

Iris includes a full alarm, stopwatch, and countdown-timer toolset for your desk work:

  • Alarm clock (alarm_popup.py / alarm_sound.py) — set alarms from your PC and dismiss or snooze them right from the panel.
  • On-screen stopwatch (stopwatch.py) — a floating, dismissable stopwatch overlay for timing anything on your desk.
  • Countdown timer — the same floating overlay counts down; it warns with a few seconds to go and reappears on the screen when the timer ends.

12. Conditional Macros & Reactive Events

Iris's macro and automation engine (automations.py) evaluates live state and fires actions when conditions change — this is where "reactive" behaviour comes from.

How it works

  • Conditions — a rule activates when a tracked value (a sensor, a Vision event, a game status, a stat) matches a configured condition.
  • Reactive events — the instant a condition becomes active, Iris fires and then auto-releases when it clears.
  • Hotkey injection — actions can inject key combinations (keyboard_service.py), tap apps, or run your own scripts.
  • Lighting reactions — e.g. change the lighting to red when combat starts, via lighting_service.py and the lighting plugin.
  • Notifications, sound, HA — a triggered event can also send a notification, play a sound, or control Home Assistant.
⚡ Example: set up a Vision sensor on your health bar and a macro that turns your RGB lighting red when it tracks the combat condition — automatic reactive lighting with addons/plugins, including Home Assistant.

13. Phone Panel / PWA

The HTML/ folder is a web panel served by the app (panel_window.py + ws_bridge.py). It can also run as a PWA on your phone.

How pairing works

  1. Turn on Allow LAN access in Settings → Network.
  2. Scan the QR code on the Settings Network tab with your phone.
  3. Set a panel password and enter it on your phone to pair.
  4. Your phone stays paired until you revoke it under "Manage devices".
⚠️ For a reliable connection, reserve the Iris PC's IP as a static/DHCP-reserved address in your router. If the address changes, just re-scan the QR code.
🔒 The local connection uses HTTP (not HTTPS), so your phone may show a "connection isn't secure" warning. This is expected on a local network.

What the files do

  • index.html / script.js — the main panel UI and logic.
  • settings_renderer.js — renders the Settings page and plugin config from JSON.
  • style.css — design tokens and layout for the whole panel.
  • manifest.json + sw.js — PWA support (offline, installable).
  • login.html / login.js — pairing / password login.

15. Home Assistant

Iris can control Home Assistant entities (lights, scenes, switches) and show sensor states — from buttons, the panel, the tray, and your automations. HA is also usable as a lighting provider, so your reactive macros and plugin actions can drive HA lights (e.g. turn the smart lights red when combat starts).

Configuration

Set these in iris_config.json (or via settings):

KeyDescription
ha_urlRoot URL of your Home Assistant instance, e.g. http://192.168.1.50:8123.
ha_tokenA long-lived access token from HA → your profile → Security → Long-Lived Access Tokens.
ha_shortcutsA JSON array of entity shortcuts shown in the tray/panel.
 
{
  "ha_url": "http://192.168.1.50:8123",
  "ha_token": "YOUR_LONG_LIVED_TOKEN",
  "ha_shortcuts": [
    { "name": "Desk Lamp", "entity_id": "light.desk_lamp", "icon": "💡" }
  ]
}
💡 Iris sends REST calls to /api/services/<domain>/<service> with Authorization: Bearer <token>. The service depends on the entity type: lights/switches toggle, scenes/scripts turn on.

16. Plugins

Iris has an extensible plugin system (app/plugin_manager.py + app/plugins/). Each plugin declares settings, status, buttons, outputs, and live data.

What a plugin exposes

  • Status — connection/lifecycle state.
  • Configuration — plugin settings shown on the Plugins tab.
  • Buttons — button-box controls (e.g. Elite Dangerous hotkeys).
  • Outputs — output routing (overlay / dashboard / hardware display).
  • Live data — device-specific telemetry.

21. Troubleshooting

Display not lighting up

Check the USB connection and that the correct serial_port is set (try "auto"). Confirm the firmware was flashed (you should see the boot self-test flash).

OpenRGB not connecting

OpenRGB must have the SDK server enabled (OpenRGB → SDK Server tab → start server on port 6742). The plugin tries the configured port, then 6742 and 6749.

Home Assistant not responding

Verify ha_url is reachable from the PC and the ha_token is a valid long-lived token with the needed scopes.

Phone can't connect to the panel

Ensure LAN access is enabled, the phone and PC are on the same network, and the PC's IP is stable. Re-scan the QR code if the address changed.

All LEDs suddenly light up

The MAX7219 failsafe should shut the display off after 60 s of no serial traffic. Ensure serial_comm.py keeps communicating and the PC app stays alive.

OCR returning no text

OCR relies on the Windows OCR language pack. Ensure the matching language pack is installed and that the captured region contains legible text. Protected/DRM content may capture black.

Vision sensor not triggering

A vision sensor only captures while its target app/process is running. Re-calibrate the region if you move the target to another monitor, since regions are anchored to the display they were captured on.

Per-app volume shows the wrong app

The mixer tracks the foreground application's audio session. Bring the app you want to adjust to the foreground, or use the session list to target it directly.
