1. Overview

Iris is a Windows desktop companion that takes data from your PC and pushes it to a physical MAX7219 LED matrix display driven by an ESP8266/ESP32 microcontroller over USB serial. It also runs a floating overlay and a phone/PWA panel for control.

The system has five main parts:

  • Python desktop app (app/) — gathers stats, services, and drives everything.
  • ESP firmware (firmware/) — receives commands from the PC and lights the display.
  • MAX7219 display — the physical 8×8 LED matrix modules.
  • HTML panel / PWA (HTML/) — a web panel for pairing and phone control.
  • Android app (android/) — a native companion-device app.
💡 You can use Iris with just the desktop app and overlay (no hardware) — the display parts are optional.

3. Hardware & Wiring

What each part does

  • ESP8266 (Wemos D1 Mini) / ESP32 — the brain of the display. It listens on USB serial for commands from the PC and drives the LED matrix over SPI.
  • MAX7219 LED matrix — 8×8 dot-matrix modules. Iris uses 4 daisy-chained modules (FC16_HW). Each MAX7219 chip drives one 8×8 panel.
  • USB cable — powers the ESP and carries serial data between the PC and the micro.

Wiring table (MAX7219 → D1 Mini)

MAX7219 PinD1 Mini PinNotes
VCC5VPower (also feeds the LED matrix).
GNDGNDCommon ground.
DIND7 (GPIO13)SPI data in.
CLKD5 (GPIO14)SPI clock.
CSD2 (GPIO4)SPI chip select.
⚠️ The MAX7219 has a built-in failsafe: if the PC app crashes or disconnects for 60 seconds, the display forces itself off to prevent a runaway all-LEDs-on state (which can draw ~5A and melt the case). Any serial command re-activates it.

SPI wiring diagram

MAX7219 | D1 Mini VCC ─────────── 5V GND ─────────── GND DIN ─────────── D7 (GPIO13) CLK ─────────── D5 (GPIO14) CS ─────────── D2 (GPIO4)

4. Flashing the Firmware

The firmware lives in firmware/d1mini/main/. Follow these steps:

1

Open the sketch

Open firmware/d1mini/main/main.ino in the Arduino IDE.

2

Install board support

In File → Preferences, add the ESP8266 boards URL to "Additional Boards Manager URLs":

http://arduino.esp8266.com/stable/package_esp8266com_index.json

Then Tools → Board → Boards Manager, search "ESP8266", and install.

3

Select your board

Under Tools → Board, select your board (e.g. "LOLIN(WEMOS) D1 mini"). Set the correct Port for your USB device.

4

Upload

Click the Upload button (→). The IDE compiles and flashes the firmware.

5

Boot self-test

On power-up you'll see a 250 ms all-LEDs flash. That's the intentional boot self-test (TEST=ON), not a fault.

5. Desktop App

The Python app in app/ is the core of Iris. Here's how to run it.

1

Clone the repo

git clone https://github.com/iamfud/iris.git
cd iris
2

Install Python dependencies

pip install -r requirements.txt

This installs pressing libraries: pystray (tray icon), Pillow (rendering), pyserial (USB), requests (HTTP/HA), psutil (system stats), pywebview (HTML panel), and more.

3

Run the app

python app/main.py

The app starts in your system tray. Click the tray icon or press the global hotkey Ctrl+Alt+I to toggle the floating overlay.

Key modules — what each file does

FilePurpose
app/main.pyEntry point — wires providers, serial, tray, and window together.
app/main_window.pyiPhone-shaped floating overlay window with gauges, tiles, and HA shortcuts.
app/serial_comm.pyUSB serial bridge that sends stats/commands to the ESP.
app/win_platform.pyWindows-specific helpers (process checks, hotkeys, file dialogs, icon extraction).
app/config.pyJSON configuration load/save.

app/providers/Data providers: Stats, HA, Media (SMTC), OpenRGB, etc.
app/ws_bridge.pyHTTP/WebSocket bridge that serves the HTML panel API.
app/panel_window.pyHosts the HTML panel via pywebview.
app/plugin_manager.pyDiscovers, loads, and coordinates plugins.

6. Phone Panel / PWA

The HTML/ folder is a web panel served by the app (panel_window.py + ws_bridge.py). It can also run as a PWA on your phone.

How pairing works

  1. Turn on Allow LAN access in Settings → Network.
  2. Scan the QR code on the Settings Network tab with your phone.
  3. Set a panel password and enter it on your phone to pair.
  4. Your phone stays paired until you revoke it under "Manage devices".
⚠️ For a reliable connection, reserve the Iris PC's IP as a static/DHCP-reserved address in your router. If the address changes, just re-scan the QR code.
🔒 The local connection uses HTTP (not HTTPS), so your phone may show a "connection isn't secure" warning. This is expected on a local network.

What the files do

  • index.html / script.js — the main panel UI and logic.
  • settings_renderer.js — renders the Settings page and plugin config from JSON.
  • style.css — design tokens and layout for the whole panel.
  • manifest.json + sw.js — PWA support (offline, installable).
  • login.html / login.js — pairing / password login.

8. Home Assistant

Iris can control Home Assistant entities (lights, scenes, switches) and show sensor states.

Configuration

Set these in iris_config.json (or via settings):

KeyDescription
ha_urlRoot URL of your Home Assistant instance, e.g. http://192.168.1.50:8123.
ha_tokenA long-lived access token from HA → your profile → Security → Long-Lived Access Tokens.
ha_shortcutsA JSON array of entity shortcuts shown in the tray/panel.
 
{
  "ha_url": "http://192.168.1.50:8123",
  "ha_token": "YOUR_LONG_LIVED_TOKEN",
  "ha_shortcuts": [
    { "name": "Desk Lamp", "entity_id": "light.desk_lamp", "icon": "💡" }
  ]
}
💡 Iris sends REST calls to /api/services/<domain>/<service> with Authorization: Bearer <token>. The service depends on the entity type: lights/switches toggle, scenes/scripts turn on.

9. Plugins

Iris has an extensible plugin system (app/plugin_manager.py + app/plugins/). Each plugin declares settings, status, buttons, outputs, and live data.

What a plugin exposes

  • Status — connection/lifecycle state.
  • Configuration — plugin settings shown on the Plugins tab.
  • Buttons — button-box controls (e.g. Elite Dangerous hotkeys).
  • Outputs — output routing (overlay / dashboard / hardware display).
  • Live data — device-specific telemetry.

Bundled plugins

PluginFolderWhat it does
Elite Dangerousapp/plugins/elite_dangerous/Reads the game journal for ship/status/telemetry and drives button-box controls.
OpenRGBapp/plugins/openrgb/Controls RGB lighting via the OpenRGB SDK server, switching profiles and colors.
PC Statsapp/plugins/pc_stats/Reports CPU/GPU temp, usage, FPS.
Visionapp/plugins/vision/Screen-analysis sensors that watch a screen region and fire events on colour conditions.
🧩 Plugins are self-contained. A plugin's connector.py is the adapter to its external source; iris never talks to the source except through the connector.

11. Build & Package

To build a standalone Windows executable and installer:

1

Run the build script

build.bat

This uses PyInstaller (Iris.spec) to bundle the app. Output: dist/Iris.exe.

2

Create the installer

The Iris_Setup.iss is an Inno Setup script that packages dist/Iris.exe and dependencies. Build it in Inno Setup to produce Installer/Iris_Setup.exe.

14. Troubleshooting

Display not lighting up

Check the USB connection and that the correct serial_port is set (try "auto"). Confirm the firmware was flashed (you should see the boot self-test flash).

OpenRGB not connecting

OpenRGB must have the SDK server enabled (OpenRGB → SDK Server tab → start server on port 6742). The plugin tries the configured port, then 6742 and 6749.

Home Assistant not responding

Verify ha_url is reachable from the PC and the ha_token is a valid long-lived token with the needed scopes.

Phone can't connect to the panel

Ensure LAN access is enabled, the phone and PC are on the same network, and the PC's IP is stable. Re-scan the QR code if the address changed.

All LEDs suddenly light up

The MAX7219 failsafe should shut the display off after 60 s of no serial traffic. Ensure serial_comm.py keeps communicating and the PC app stays alive.
