PC Companion Overlay

Your PC, on a physical display.

Iris is a Windows desktop companion that streams PC stats, notifications, media info, and Home Assistant entities to an ESP8266/ESP32-driven MAX7219 LED matrix — plus a floating overlay and a phone/PWA panel for full control.

Features

Everything your desk deserves

From hardware telemetry to smart-home control, Iris brings your PC's data to the physical world.

📊

Live PC Stats

CPU/GPU temperature, usage, and FPS streamed in real time to the matrix display.

🕐

Clock & Date

Large clock with date, minute bar, and an ambient animated "eyes" doodle.

🔔

Notifications

Windows notifications mirrored onto the secondary display and your phone panel.

🏠

Home Assistant

View sensor states and trigger shortcuts for lights, scenes, and switches.

⏰

Alarm Clock

Set alarms from your PC; dismiss or snooze right from the panel.

🎵

Media Controls

Now-playing display via Windows SMTC, with album art and playback status.

🎨

OpenRGB

Sync RGB lighting profiles over the OpenRGB SDK server.

🎮

Vision & Plugins

Screen-analysis vision sensors and a plugin system for Elite Dangerous, OpenRGB, and more.

Hardware

What you'll need

Iris runs on an ESP8266/ESP32 plus a MAX7219 LED matrix, connected over USB serial.

📟

Display

MAX7219 LED matrix, FC16_HW type — 4 daisy-chained 8×8 modules.

🔌

Microcontroller

ESP8266 (Wemos D1 Mini) or ESP32, flashed with the bundled firmware.

🖥️

PC

Windows 10/11 with Python 3.10+ running the Iris desktop app.

Components

An integrated system

Iris is more than a display — it's a full companion stack.

🗔

Desktop App

Python app with a system tray, floating overlay, and all the data plumbing.

📱

Phone Panel / PWA

A web panel (installable as a PWA) for pairing and controlling Iris from your phone.

🤖

Android App

A native Android companion in android/ for companion-device use.

🧩

Plugin System

Extensible plugins for Elite Dangerous, OpenRGB, PC stats, and vision sensors.
